# Machine Learning

A collection of machine learning implementations and projects built with Python and scikit-learn.

This repository documents my learning journey through different machine learning algorithms. I implement each algorithm in Python, apply it to different datasets, and evaluate the resulting models.

## Topics Covered

- Linear Regression
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Trees
- Support Vector Machines (SVM)
- Ensemble Learning
- Random Forest

## Tools & Libraries

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
